# Pocket Banana

Landingpage und Shop-Entwurf für Pocket Banana: eine Mini-Kapsel für den Gurt mit Intimtüchern, selbst gestaltbar und mit Tücher-Abo.

- Statische Seite, eine Datei: `index.html`
- Sprachen: Deutsch / Englisch
- Konfigurator (Farbe, Deckel, Muster, Gravur), Abo-Auswahl, Warenkorb (Demo, keine Kasse angebunden)
- Preise sind Platzhalter

Live: https://break-gmbh.github.io/pocket-banana/
